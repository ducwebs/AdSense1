¿Qué es Make y por qué usarlo con Gmail?

Make (antes Integromat) es una plataforma de automatización visual sin código que conecta aplicaciones entre sí mediante flujos llamados escenarios. En lugar de escribir código, arrastra módulos y los conectas visualmente. Es el "pegamento" que une Gmail, la IA y todas tus herramientas.

  • 🤖

Paso 2: Conectar Gmail a Make de forma segura

Make necesita permiso para leer y enviar correos desde tu Gmail. Usamos la autenticación OAuth 2.0 de Google — el estándar de seguridad más alto. Tu contraseña nunca se expone ni se almacena en Make.

1

Ir a Connections y buscar Gmail

En el menú lateral de Make, haz clic en Connections → "Create a connection" (botón azul, esquina superior derecha). En el buscador escribe Gmail y selecciona Gmail (no la versión "Legacy").

Paso 4: Obtener tu API Key de OpenAI y conectarla

La API Key es la "contraseña" que permite a Make comunicarse con los modelos de IA de OpenAI. El proceso tarda menos de 5 minutos.

1

Crear cuenta en OpenAI y obtener la API Key

Ve a platform.openai.com. Crea una cuenta con tu Gmail. Después navega a:

  • Avatar (esquina superior derecha) → View API Keys
  • Clic en "Create new secret key"
  • Dale un nombre descriptivo: Make-Gmail-Bot
  • Copia la clave inmediatamente — solo se muestra una vez
⚠️

Agrega créditos antes de continuar: OpenAI requiere saldo prepagado. Carga un mínimo de $5 USD (~$90 MXN) en Billing → Add payment method. Con eso tienes para procesar miles de correos con gpt-4o-mini.

Paso 5: Crear el Prompt de IA para respuestas inteligentes

El prompt es la instrucción que le damos a la IA. Es el paso más importante: un buen prompt produce respuestas que parecen escritas por ti; uno malo produce textos genéricos y robóticos. Aquí te damos una plantilla probada.

1

Configurar el modelo y parámetros básicos

En el módulo OpenAI, configura estos campos primero:

Configuración — Módulo OpenAI en Make
// Parámetros del módulo "Create a Chat Completion" Model: gpt-4o-mini // Más barato y rápido — ideal para correos Max Tokens: 600 // Suficiente para una respuesta de correo completa Temperature: 0.7 // Balance entre creatividad y precisión Role (System): system // Mensaje de sistema para definir el contexto
2

El prompt base — System Message

En el campo Messages → Role: system → Content, pega este prompt y personalízalo con tus datos:

System Prompt — Personaliza con tus datos
Eres el asistente de correo electrónico de [NOMBRE DE TU EMPRESA]. Tu tono es profesional pero cercano, como se usa en México y Latinoamérica. Contexto de la empresa: - Nombre: [NOMBRE DE TU EMPRESA] - Servicio principal: [QUÉ VENDES / QUÉ OFRECES] - Precios: [RANGOS DE PRECIOS SI APLICA] - Horario de atención: [HORARIO] - Página web: [TU SITIO WEB] Reglas para responder: 1. Saluda al remitente por su nombre si aparece en el correo 2. Responde directamente a su consulta, de forma útil y específica 3. Sé conciso: máximo 3 párrafos 4. Termina con una despedida profesional y firma con "[TU NOMBRE] - [EMPRESA]" 5. Escribe SOLO el cuerpo del correo, sin asunto ni saludos de encabezado extra 6. Si el correo es spam, publicidad o completamente ilegible, responde: SKIP
3

El mensaje de usuario — con variables dinámicas de Gmail

Agrega otro mensaje con Role: user. Aquí mapeas las variables del correo recibido — haz clic en el campo y aparecerá el mapeador de variables de Make:

User Message — Variables de Gmail (copiar y mapear en Make)
// Las variables {{...}} se mapean automáticamente desde el módulo Gmail // En Make, al hacer clic en el campo aparece el selector de variables He recibido el siguiente correo electrónico: De: {{1.from}} Asunto: {{1.subject}} Fecha: {{1.date}} Mensaje: {{1.text}} Por favor, redacta una respuesta adecuada siguiendo las reglas del sistema.

Paso 7: Filtros inteligentes para no responder spam

Sin filtros, el bot respondería todos los correos: spam, boletines, notificaciones de redes sociales, avisos de bancos... Eso agotaría tu cuota de operaciones y podría crear problemas. Añadimos dos filtros estratégicos.

1

Filtro entre Gmail Watch y OpenAI — excluir automáticos

Haz clic derecho en la flecha que conecta el módulo 1 y el módulo 2 → "Add a filter". Configura con estas condiciones (todas unidas por AND):

Filtro 1 — Excluir correos automáticos y no deseados
// Condición 1: No es un correo de "no-reply" Field: {{1.from}} Operator: Does not contain Value: noreply // Condición 2 (AND): No tiene etiqueta SPAM Field: {{1.labelNames[]}} Operator: Does not contain Value: SPAM // Condición 3 (AND): No es categoría Promociones Field: {{1.labelNames[]}} Operator: Does not contain Value: CATEGORY_PROMOTIONS // Condición 4 (AND): No es notificación social Field: {{1.labelNames[]}} Operator: Does not contain Value: CATEGORY_SOCIAL
🖼️
📸 Captura sugerida #13
Panel de configuración de un filtro en Make mostrando las condiciones configuradas con los operadores "Does not contain". Mostrar el botón "AND" entre condiciones. Esta captura es útil porque los filtros de Make pueden ser confusos para principiantes.

Filtros en Make — cada condición AND reduce el riesgo de responder correos no deseados.

2

Filtro entre OpenAI y Send Email — respetar la instrucción SKIP

Recuerda que en el prompt le pedimos a la IA que responda "SKIP" si el correo no tiene sentido. Añade un segundo filtro entre los módulos 2 y 3:

Filtro 2 — No enviar si la IA devolvió "SKIP"
// Solo enviar correo si la IA NO respondió "SKIP" Field: {{2.choices[].message.content}} Operator: Does not equal (case insensitive) Value: SKIP

Optimizaciones avanzadas — Lleva tu bot al siguiente nivel

Usar gpt-4o-mini para ahorrar costos

Para la mayoría de respuestas de correo, gpt-4o-mini es idéntico a gpt-4o en calidad percibida, pero 20 veces más barato. Reserva gpt-4o solo si la precisión es crítica (contratos, respuestas legales).

Añadir "Human in the Loop"

Antes del módulo Send Email, inserta un módulo de Telegram o Email que te envíe la respuesta para revisión y aprobación. Después de aprobarla, un webhook activa el envío final. Esto es ideal cuando el bot es nuevo y quieres supervisar la calidad.

Guardar cada correo en Airtable o Google Sheets

Agrega un módulo de Airtable o Google Sheets para registrar cada correo procesado con: remitente, asunto, resumen de la consulta, respuesta enviada y timestamp. Así tienes un historial completo y puedes analizar los temas más frecuentes.

FAQ — Automatizar correos con Gmail + Make

¿Es gratis automatizar correos con Gmail y Make?

Make tiene un plan gratuito con 1,000 operaciones al mes — suficiente para procesar hasta ~330 correos (3 operaciones por correo). Gmail es completamente gratuito. El único costo potencial es la API de OpenAI: aproximadamente $0.002 USD por correo con gpt-4o-mini, menos de $35 MXN por 1,000 correos.

¿Necesito saber programar para este tutorial?

No. Make es 100% visual (no-code). Todo se hace arrastrando módulos, conectándolos y rellenando formularios. Las únicas "variables" como {{1.from}} se crean automáticamente al mapear campos — no hay que escribirlas a mano.

¿Funciona con Gmail empresarial (Google Workspace)?

Sí. Funciona perfectamente tanto con cuentas @gmail.com personales como con Google Workspace para empresas (antes G Suite). El proceso de autorización OAuth es idéntico en ambos casos.

¿Cada cuánto revisa Make los correos nuevos?

Con el plan gratuito de Make, el intervalo mínimo es cada 15 minutos. Con el plan Core ($9 USD/mes) puedes reducirlo a cada 1 minuto. Para procesamiento casi instantáneo necesitas configurar un webhook de Gmail, lo que requiere un plan de pago de Make y Google Cloud. Para la mayoría de negocios, 15 minutos es más que suficiente.

¿El bot responde en mi nombre o se nota que es IA?

Depende completamente de cómo configures el prompt. Si incluyes información detallada de tu negocio, tu tono habitual y ejemplos de tus respuestas previas, las respuestas son prácticamente indistinguibles de las tuyas. Muchos usuarios en México y Latinoamérica reportan que sus clientes no han notado diferencia.

¿Puedo usar Claude de Anthropic en lugar de ChatGPT?

Sí. Make tiene módulos nativos para Anthropic (Claude). El proceso es idéntico: busca "Anthropic" en el buscador de módulos, conecta tu API Key desde console.anthropic.com y el resto del flujo funciona igual. Claude es especialmente bueno para español formal y comunicaciones de negocios.

¿Qué pasa si la IA genera una respuesta incorrecta o inapropiada?

Puedes agregar un paso de revisión humana antes del envío ("Human in the Loop"): Make te manda la respuesta por Telegram o email para que la apruebes. Al confirmar, un segundo módulo envía el correo. Esto es ideal durante las primeras semanas de uso, hasta que compruebes que el bot funciona bien para tu caso específico.

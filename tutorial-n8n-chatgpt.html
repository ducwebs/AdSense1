¿Por qué conectar n8n con ChatGPT?

n8n es una plataforma de automatización de código abierto que te permite conectar cientos de aplicaciones y servicios mediante flujos de trabajo visuales. ChatGPT (a través de la API de OpenAI) es el motor de inteligencia artificial más versátil disponible hoy. Cuando los combinas, obtienes automatizaciones que no solo mueven datos, sino que los entienden.

Un flujo de trabajo tradicional puede mover un correo a una carpeta. Un flujo inteligente con ChatGPT puede leer ese correo, determinar si es urgente, redactar una respuesta personalizada, agendar una reunión y notificarte por WhatsApp, todo sin que toques un botón.

🌎

Para México y Latinoamérica: n8n self-hosted es completamente gratuito y puedes instalarlo en tu computadora o en un servidor de bajo costo (desde $5 USD/mes en DigitalOcean, Vultr o Contabo). La API de OpenAI se paga en dólares, pero los costos son mínimos: con $5 USD puedes procesar miles de mensajes con gpt-4o-mini.

Paso 1: Obtener tu API Key de OpenAI

La API Key es la "contraseña" que le da acceso a n8n para usar los modelos de OpenAI. Sigue estos pasos para obtenerla:

1

Accede a la plataforma de OpenAI

Ve a platform.openai.com e inicia sesión con tu cuenta de OpenAI. Si no tienes cuenta, créala en el mismo sitio. Los nuevos usuarios reciben créditos gratuitos para empezar.

3

Crear una nueva clave

Haz clic en el botón "Create new secret key" (crear nueva clave secreta). Asígnale un nombre descriptivo, por ejemplo: n8n-automatizacion. Esto te ayuda a identificarla si después quieres revocarla o crear nuevas.

En n8n, siempre guárdala como una credencial segura (te explicamos cómo en el siguiente paso).

Paso 3: Tu primer workflow con ChatGPT

Vamos a crear el workflow más básico posible: un trigger manual que envía un texto a ChatGPT y muestra la respuesta. Es la base de todo lo que haremos después.

1

Crear un nuevo workflow

En n8n, haz clic en "New Workflow" (botón naranja o el símbolo "+" en la barra lateral). Se abrirá el editor de flujos con un canvas vacío. Dale un nombre al workflow haciendo clic en "My Workflow" en la parte superior: ponle algo descriptivo como "Test ChatGPT API".

🖼️
Captura de pantalla
Editor de workflows de n8n mostrando el canvas vacío con el cursor listo para añadir el primer nodo

2

Agregar el nodo Manual Trigger

Haz clic en el botón "+" en el canvas o en "Add first step". Busca "Manual Trigger" y agrégalo. Este nodo sirve para ejecutar el workflow manualmente con un clic, perfecto para pruebas. En producción lo reemplazarás por un disparador real (webhook, email, formulario, etc.).

3

Agregar el nodo OpenAI

Haz clic en el símbolo "+" que aparece a la derecha del nodo Manual Trigger para agregar el siguiente nodo. Busca "OpenAI" en el panel de nodos. Selecciona el nodo "OpenAI". En el panel de configuración que se abre a la derecha, configura lo siguiente:

• Credential: Selecciona la credencial que creaste en el paso anterior.
• Resource: Message a Model
• Model: gpt-4o-mini (recomendado para pruebas)
• Messages: Haz clic en "Add Message" → Role: user → Content: ¿Cuál es la capital de México? Responde en una sola oración.

Paso 4: Prompts dinámicos con datos reales

La verdadera magia ocurre cuando el prompt que envías a ChatGPT no es estático, sino que incluye datos dinámicos del flujo: el texto de un email, el mensaje de un cliente, el contenido de un formulario. Para eso usamos las expresiones de n8n.

// Expresiones de n8n

En cualquier campo de texto de n8n puedes usar {{ }} para insertar el valor de datos anteriores en el flujo. Por ejemplo, si el nodo anterior entregó un campo llamado emailBody, puedes usarlo así:

n8n Expression — Prompt dinámico
// En el campo "Content" del nodo OpenAI: Eres un asistente de soporte para una empresa mexicana. Analiza el siguiente correo de un cliente y determina: 1. ¿Es una queja, consulta o solicitud de reembolso? 2. ¿Qué tan urgente es del 1 al 10? 3. Redacta una respuesta amable y profesional en español. Correo del cliente: {{ $json.emailBody }} Nombre del cliente: {{ $json.customerName }} Asunto: {{ $json.emailSubject }} Responde ÚNICAMENTE en formato JSON con esta estructura: { "tipo": "queja|consulta|reembolso", "urgencia": 1-10, "respuesta": "texto de la respuesta" }
💡

Truco pro: Siempre que necesites que ChatGPT te devuelva datos estructurados (para usarlos en nodos posteriores), pídele que responda en formato JSON. Esto hace que parsear la respuesta sea trivial. En la sección siguiente te mostramos cómo extraer esos datos.

// System Prompt: dale personalidad a tu IA

En el nodo OpenAI puedes agregar un mensaje con el rol system antes del mensaje del usuario. El system prompt le dice a ChatGPT cómo debe comportarse en todo el flujo:

System Prompt — Ejemplo soporte empresarial
Eres María, la asistente virtual de Servicios Rápidos México SA de CV. Tu objetivo es clasificar y responder mensajes de clientes de forma profesional, empática y en español mexicano. REGLAS: - Siempre responde en español - Usa un tono amable pero profesional - Si no puedes resolver algo, escala a un humano - No inventes información sobre productos o precios - Siempre firma con "María - Asistente Virtual"

Paso 5: Parsear la respuesta de ChatGPT

Cuando ChatGPT responde con un JSON, la respuesta llega como texto plano en el campo message.content. Para usar esos datos en nodos posteriores (guardar en Airtable, enviar por email, etc.), necesitas convertirlos de texto a un objeto JSON real. Para eso usamos un nodo Code en n8n.

1

Agregar un nodo Code después del nodo OpenAI

Haz clic en el "+" después del nodo OpenAI. Busca "Code" y agrégalo. Selecciona el lenguaje JavaScript. Este nodo te permite escribir código que transforma los datos entre nodos.

JavaScript — Nodo Code de n8n
// Obtener el texto de respuesta de ChatGPT const aiText = $input.first().json.message.content; try { // Limpiar posibles bloques de código markdown (```json ... ```) let clean = aiText.trim(); if (clean.startsWith('```')) { clean = clean.replace(/```json\n?/g, '').replace(/```/g, '').trim(); } // Extraer el JSON (por si hay texto antes o después) const start = clean.indexOf('{'); const end = clean.lastIndexOf('}') + 1; const jsonStr = clean.substring(start, end); // Parsear el JSON const parsed = JSON.parse(jsonStr); // Retornar el objeto parseado + el texto original por si lo necesitas return [{ json: { ...parsed, rawResponse: aiText, processedAt: new Date().toISOString() } }]; } catch (e) { // Si falla el parse, retornar el texto como está para no romper el flujo return [{ json: { error: 'No se pudo parsear la respuesta', raw: aiText, errorMessage: e.message } }]; }
🖼️

Errores comunes y cómo solucionarlos

!

Error: "Authentication failed" o "Invalid API Key"

Causa: La API Key está mal copiada, tiene espacios al inicio/final, o fue revocada en OpenAI.

Solución: Ve a n8n Settings → Credentials, edita la credencial de OpenAI y vuelve a pegar la clave desde platform.openai.com/api-keys. Verifica que no tenga espacios extra.

!

Error: "Insufficient quota" o "You exceeded your current quota"

Causa: Te quedaste sin créditos en OpenAI o tu límite mensual fue alcanzado.

Solución: Ve a platform.openai.com/billing y agrega saldo. Puedes configurar un límite máximo mensual para no gastar de más. Recomendamos comenzar con $10 USD.

!

Error: JSON.parse falla en el nodo Code

Causa: ChatGPT no devolvió un JSON válido. A veces agrega texto introductorio como "Aquí está el JSON solicitado:" antes del objeto.

Solución: Usa el script de parseo con limpieza de markdown que te dimos arriba. Si el problema persiste, agrega al prompt: "Responde ÚNICAMENTE con el JSON, sin ningún texto adicional, sin backticks, sin explicaciones."

!

El workflow no se activa con el Gmail Trigger

Causa: El workflow no está activado (solo guardado) o la credencial de Gmail expiró.

Solución: Asegúrate de hacer clic en el toggle "Active" en la esquina superior derecha del editor. Verifica también que la credencial de Google siga autorizada en tu cuenta.

Preguntas frecuentes

¿Necesito saber programar para conectar n8n con ChatGPT?

No necesitas ser programador para hacer flujos básicos e intermedios. n8n tiene una interfaz visual donde arrastras y sueltas nodos. El único momento donde se usa código es en el nodo Code para parsear respuestas JSON, y en este tutorial te damos el código listo para copiar y pegar.

Para flujos avanzados, conocer conceptos básicos de JavaScript ayuda, pero no es obligatorio para empezar.

¿Cuánto cuesta usar ChatGPT API con n8n en México?

n8n self-hosted (instalado en tu computadora o servidor) es completamente gratuito. La API de OpenAI tiene un costo por uso:

• gpt-4o-mini: $0.15 USD por millón de tokens de entrada y $0.60 por millón de salida. Con $5 USD puedes procesar decenas de miles de mensajes cortos.
• gpt-4o: Aproximadamente 30 veces más caro que mini.

Para una pequeña empresa que procesa 500 emails al mes, el costo con gpt-4o-mini sería menor a $1 USD mensual.

¿n8n funciona en español?

La interfaz de n8n está principalmente en inglés, pero no necesitas saber inglés avanzado para usarlo. Los nombres de los nodos son descriptivos y hay muchos tutoriales en español (como este). ChatGPT, por su parte, entiende y responde en español perfectamente, incluyendo modismos mexicanos y latinoamericanos.

¿Qué diferencia hay entre usar el nodo HTTP Request y el nodo OpenAI en n8n?

El nodo OpenAI es la forma recomendada: tiene todos los campos pre-configurados, maneja la autenticación automáticamente y es más fácil de mantener. El nodo HTTP Request te permite hacer llamadas directas a la API de OpenAI (o cualquier otra API) con más control, pero requiere configurar manualmente los headers, el body y la autenticación. Para la mayoría de los casos, usa el nodo nativo de OpenAI.

¿Puedo usar n8n Cloud en lugar de instalarlo en mi computadora?

Sí. n8n Cloud es la opción hosted (en la nube) que no requiere instalación. Tiene una prueba gratuita de 14 días. Después cuesta desde $20 USD/mes. La ventaja es que funciona 24/7 sin necesidad de tener tu computadora encendida. Para empezar y aprender, usar n8n self-hosted en tu computadora es perfectamente válido y gratis.

¿ChatGPT recuerda las conversaciones anteriores en los workflows de n8n?

No por defecto. Cada llamada a la API de OpenAI es independiente. Si quieres que ChatGPT "recuerde" el contexto de una conversación (por ejemplo, para un chatbot multi-turno), debes incluir el historial de mensajes anteriores en cada nueva llamada a la API. n8n tiene el nodo "AI Agent" que facilita esto con memoria integrada. En tutoriales posteriores cubriremos cómo construir chatbots con memoria usando n8n.

Cómo instalar n8n en tu computadora: Windows, Mac y Linux (Guía completa 2025)

n8n es una de las herramientas de automatización más poderosas del mundo — y lo mejor: es 100% gratis cuando la instalas en tu propia computadora. En esta guía completa te enseñamos a instalar n8n paso a paso en Windows, Mac y Linux, desde cero, sin necesitar conocimientos técnicos avanzados. En menos de 30 minutos tendrás tu propio servidor de automatización corriendo localmente.

¿Qué es n8n y por qué instalarlo localmente?

n8n (pronunciado "n-eight-n") es una herramienta de automatización de flujos de trabajo de código abierto. Funciona de forma similar a Zapier o Make, pero con ventajas clave:

Característican8n (local)ZapierMake
Precio baseGratis$20+/mes$9+/mes
Límite de operacionesSin límiteLimitadoLimitado
Privacidad de datos100% localEn la nubeEn la nube
PersonalizaciónTotalLimitadaMedia
Código JavaScriptSíLimitadoSí
Facilidad inicialMediaAltaAlta
💡

¿Cuándo conviene n8n local? Si procesas datos sensibles de clientes, quieres automatizaciones sin límite de operaciones, o simplemente no quieres pagar mensualidad. Para un negocio que automatiza procesos internos, n8n local es la opción más económica y potente.

Requisitos previos antes de instalar n8n

Antes de instalar n8n necesitas tener Node.js instalado en tu computadora. Node.js es el entorno de ejecución sobre el que corre n8n. Aquí los requisitos mínimos:

⚡

Node.js v18+

Versión 18 o superior (LTS recomendado). Es el único requisito técnico.

💾

RAM mínima

2 GB mínimo. Con 4 GB o más tendrás una experiencia cómoda y fluida.

💿

Espacio en disco

~500 MB para n8n y sus dependencias. Más si guardas muchos datos de flujos.

🌐

Conexión a internet

Para descargar n8n e integrar con servicios externos (Gmail, Slack, etc.).

⚠️

Importante: Si ya tienes Node.js instalado, verifica la versión ejecutando node -v en la terminal. Si es menor a v18, actualiza antes de continuar o tendrás errores al instalar n8n.

Instalación de n8n según tu sistema operativo

Selecciona tu sistema operativo para ver las instrucciones específicas:

🪟 Windows 10 / 11

// Paso 1 — Instalar Node.js en Windows

1

Descargar Node.js

Ve a nodejs.org y descarga el instalador de la versión LTS (la que dice "Recommended For Most Users"). Elige el instalador de 64-bit para Windows.

Captura pendiente
🖼️ Captura sugerida Página de descarga de nodejs.org resaltando el botón LTS para Windows 64-bit
2

Ejecutar el instalador

Abre el archivo .msi descargado y sigue el asistente de instalación. Acepta los términos de licencia, deja las opciones por defecto y haz clic en "Install". El proceso tarda 1-2 minutos.

Asegúrate de que la opción "Add to PATH" esté marcada — esto permite usar Node.js desde cualquier terminal.

🖼️ Captura sugerida Asistente de instalación de Node.js en Windows mostrando la opción "Add to PATH" marcada
3

Verificar la instalación

Abre Símbolo del sistema (busca "cmd" en el menú Inicio) o PowerShell y ejecuta:

CMD / PowerShell — Windows
> node -v v20.x.x ← debe mostrar v18 o superior > npm -v 10.x.x ← npm viene incluido con Node.js
Captura pendiente
🖼️ Captura sugerida PowerShell mostrando los comandos "node -v" y "npm -v" con sus versiones correctas

// Paso 2 — Instalar n8n en Windows

4

Instalar n8n globalmente con npm

En tu terminal (CMD o PowerShell), ejecuta este comando. Puede tardar entre 2 y 5 minutos dependiendo de tu conexión:

CMD / PowerShell — Instalar n8n
> npm install -g n8n ← Verás muchas líneas descargando paquetes, es normal added 892 packages in 3m ← mensaje final de éxito
⚠️

Error común en Windows: Si ves un error de permisos, abre PowerShell como Administrador (clic derecho → "Ejecutar como administrador") y repite el comando.

5

Iniciar n8n

Una vez instalado, ejecuta:

CMD / PowerShell — Iniciar n8n
> n8n start ← Verás algo similar a esto: ✔ n8n ready on 0.0.0.0, port 5678 ✔ Version: 1.x.x ✔ Editor is now accessible via: http://localhost:5678
6

Abrir n8n en el navegador

Abre tu navegador (Chrome, Edge o Firefox) y ve a:

http://localhost:5678

Verás la pantalla de bienvenida de n8n para crear tu cuenta local.

💡

Tip Windows: Para que n8n no cierre cuando cierras la terminal, puedes instalarlo como servicio con npm install -g pm2 y luego pm2 start n8n. Así corre en segundo plano. Te explicamos esto en la sección de configuración avanzada más abajo.

🍎 macOS (Intel y Apple Silicon M1/M2/M3)

// Paso 1 — Instalar Node.js en Mac

Tienes dos formas de instalar Node.js en Mac. Recomendamos usar Homebrew (el gestor de paquetes más popular en Mac), pero también puedes descargarlo directamente.

1

Opción A (recomendada): Instalar con Homebrew

Si no tienes Homebrew, instálalo primero. Abre la aplicación Terminal (búscala con Cmd+Espacio) y ejecuta:

Terminal — macOS — Instalar Homebrew
$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" ← Pedirá tu contraseña de Mac y tardará unos minutos
2

Instalar Node.js con Homebrew

Una vez instalado Homebrew, instala Node.js con:

Terminal — macOS — Instalar Node.js
$ brew install node ← Homebrew descarga e instala Node.js automáticamente ==> node 20.x.x installed successfully
ℹ️

Opción B — Sin Homebrew: Ve a nodejs.org, descarga el instalador .pkg para macOS y sigue el asistente. Funciona igual en Intel y Apple Silicon (M1/M2/M3).

3

Verificar instalación

En la Terminal, verifica que Node.js está correctamente instalado:

Terminal — macOS — Verificar
$ node -v v20.x.x $ npm -v 10.x.x
Captura pendiente
🖼️ Captura sugerida Terminal de macOS mostrando los comandos "node -v" y "npm -v" con sus versiones correctas

// Paso 2 — Instalar n8n en Mac

4

Instalar n8n con npm

En la Terminal, ejecuta:

Terminal — macOS — Instalar n8n
$ npm install -g n8n ← Si pide permisos, agrega "sudo" al inicio: $ sudo npm install -g n8n
⚠️

Mac Apple Silicon (M1/M2/M3): Si instalaste Node.js con Homebrew, normalmente no necesitas sudo. Si usaste el instalador .pkg de nodejs.org y ves errores de permisos, agrega sudo antes del comando.

5

Iniciar n8n

Terminal — macOS — Iniciar n8n
$ n8n start ✔ n8n ready on 0.0.0.0, port 5678 http://localhost:5678
6

Abrir en el navegador

Abre Safari, Chrome o Firefox y ve a http://localhost:5678. Crea tu usuario y contraseña en la pantalla de bienvenida.

Captura pendiente
🖼️ Captura sugerida n8n corriendo en el navegador en Mac (localhost:5678) — pantalla de registro inicial
💡

Tip Mac: Para que n8n siga corriendo cuando cierras la Terminal, puedes usar pm2. Instálalo con npm install -g pm2 y luego ejecuta pm2 start n8n. Para que arranque automáticamente al encender tu Mac: pm2 startup.

🐧 Linux — Ubuntu, Debian y derivados

// Paso 1 — Instalar Node.js en Linux

La forma más recomendada en Linux es usar NodeSource, que garantiza tener la versión correcta de Node.js desde repositorios oficiales.

1

Actualizar paquetes del sistema

Abre la terminal y ejecuta:

Bash — Linux — Actualizar sistema
$ sudo apt update && sudo apt upgrade -y
2

Instalar Node.js v20 LTS desde NodeSource

Bash — Linux — Instalar Node.js 20 LTS
# Descargar el script de instalación de NodeSource $ curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - # Instalar Node.js $ sudo apt install -y nodejs # Verificar instalación $ node -v v20.x.x $ npm -v 10.x.x
Captura pendiente
🖼️ Captura sugerida Terminal de Linux (Ubuntu) mostrando la instalación exitosa de Node.js con "node -v" y "npm -v"
ℹ️

¿Usas Fedora, CentOS o RHEL? Cambia apt por dnf o yum según tu distro. El script de NodeSource tiene instrucciones específicas para cada sistema en github.com/nodesource/distributions.

// Paso 2 — Instalar n8n en Linux

3

Instalar n8n globalmente

Bash — Linux — Instalar n8n
$ sudo npm install -g n8n ← Descarga e instala todas las dependencias (~800 paquetes) added 892 packages in 3m
4

Iniciar n8n

Bash — Linux — Iniciar n8n
$ n8n start ✔ n8n ready on 0.0.0.0, port 5678 http://localhost:5678
5

Abrir en el navegador

Ve a http://localhost:5678 en tu navegador. Si usas un servidor remoto (VPS), reemplaza localhost por la IP pública de tu servidor.

// Bonus — Correr n8n como servicio en Linux (systemd)

Para que n8n arranque automáticamente al reiniciar el servidor, crea un servicio de systemd:

Bash — Linux — n8n como servicio systemd
# Crear archivo de servicio $ sudo nano /etc/systemd/system/n8n.service # Pega este contenido (ajusta el usuario): [Unit] Description=n8n workflow automation After=network.target [Service] Type=simple User=tu-usuario ExecStart=/usr/bin/n8n start Restart=on-failure RestartSec=10 StandardOutput=syslog StandardError=syslog SyslogIdentifier=n8n Environment=N8N_PORT=5678 [Install] WantedBy=multi-user.target # Habilitar e iniciar el servicio $ sudo systemctl daemon-reload $ sudo systemctl enable n8n $ sudo systemctl start n8n $ sudo systemctl status n8n ● n8n.service - n8n workflow automation Active: active (running)

Primer inicio: configurar tu cuenta en n8n

Independientemente de tu sistema operativo, el proceso de configuración inicial en el navegador es el mismo:

1

Crear tu usuario administrador

En la pantalla de bienvenida de n8n, ingresa tu nombre, email y una contraseña segura. Este será el usuario administrador local — no se envía a ningún servidor externo.

Captura pendiente
🖼️ Captura sugerida Formulario de registro de primer usuario en n8n (localhost:5678/setup) con los campos de nombre, email y contraseña
2

Explorar el dashboard de n8n

Una vez dentro, verás el panel principal. Los elementos clave son:

  • Workflows: Tus flujos de automatización guardados
  • Credentials: Donde conectas tus cuentas (Gmail, Slack, etc.)
  • Executions: Historial de todas las ejecuciones
  • + New Workflow: Para crear tu primera automatización

🖼️ Captura sugerida Dashboard principal de n8n mostrando el menú lateral con Workflows, Credentials y Executions, y el botón "+ New Workflow"
3

Crear tu primer workflow de prueba

Haz clic en "+ New Workflow". En el editor, haz clic en "+" y busca el nodo "Manual Trigger". Añade otro nodo de "Set" para asignar valores. Haz clic en "Execute Workflow" para probarlo. Si ves el resultado sin errores, ¡n8n está funcionando perfectamente!

Errores comunes y cómo solucionarlos

ErrorSistemaCausaSolución
n8n: command not found Mac / Linux Node.js no está en el PATH Reinicia la terminal o agrega Node.js al PATH manualmente
EACCES: permission denied Mac / Linux Sin permisos en directorio npm Usa sudo npm install -g n8n o configura npm para usuario local
Error: ENOENT al iniciar Windows Ruta de instalación con espacios Instala en un directorio sin espacios, ej: C:\n8n
Puerto 5678 en uso Todos Otra app usa el puerto Inicia con N8N_PORT=5679 n8n start
Versión de Node.js antigua Todos Node.js menor a v18 Actualiza Node.js desde nodejs.org
n8n cierra al cerrar terminal Todos Proceso dependiente de la terminal Usa pm2 start n8n o el servicio de systemd (Linux)

Configuración adicional recomendada

// Variables de entorno útiles

Puedes personalizar n8n con variables de entorno antes de iniciarlo. Las más útiles:

Bash / CMD — Variables de entorno n8n
# Puerto personalizado (default: 5678) N8N_PORT=5679 # Zona horaria (importante para triggers programados) GENERIC_TIMEZONE="America/Mexico_City" # Otras zonas LATAM: # America/Bogota, America/Buenos_Aires, America/Lima # America/Santiago, America/Caracas, America/Sao_Paulo # Desactivar telemetría N8N_DIAGNOSTICS_ENABLED="false" # Forma de iniciar con variables (Linux/Mac): $ N8N_PORT=5679 GENERIC_TIMEZONE="America/Mexico_City" n8n start # En Windows (PowerShell): > $env:N8N_PORT="5679"; $env:GENERIC_TIMEZONE="America/Mexico_City"; n8n start

// Correr n8n en segundo plano con PM2

Terminal — PM2 (todos los sistemas)
# Instalar PM2 (gestor de procesos) $ npm install -g pm2 # Iniciar n8n con PM2 $ pm2 start n8n # Ver estado $ pm2 status ┌─ App name ─┬─ Status ─┬─ CPU ─┬─ Memory ─┐ │ n8n │ online │ 0.2% │ 120 MB │ # Arrancar automáticamente al reiniciar el sistema $ pm2 startup $ pm2 save # Ver logs en tiempo real $ pm2 logs n8n # Reiniciar / detener n8n $ pm2 restart n8n $ pm2 stop n8n

Preguntas frecuentes sobre instalar n8n

¿Es realmente gratis instalar n8n localmente?

Sí, 100% gratis. n8n es software de código abierto bajo licencia "Sustainable Use License". Puedes instalarlo, usarlo y automatizar todo lo que quieras sin pagar nada. Solo pagas si contratas n8n Cloud (el servicio de hosting de ellos). Instalado en tu computadora o servidor propio: completamente gratis.

¿Puedo acceder a n8n desde otros dispositivos en mi red?

Sí. Si n8n corre en tu computadora, otros dispositivos en la misma red WiFi pueden acceder usando la IP local de tu computadora en lugar de "localhost". Por ejemplo: http://192.168.1.100:5678. Para acceso desde internet necesitas configurar tu router (port forwarding) o usar un servicio como ngrok.

¿Cuánta RAM consume n8n en reposo?

En reposo, n8n consume entre 80-150 MB de RAM. Durante ejecución de flujos complejos puede subir a 300-500 MB. Para uso normal en una computadora de trabajo, el impacto es mínimo y no notarás diferencia en el rendimiento del sistema.

¿Dónde guarda n8n mis flujos de trabajo y datos?

Por defecto, n8n guarda todo en una base de datos SQLite local en la carpeta del usuario: ~/.n8n/ en Mac/Linux, o C:\Users\TuUsuario\.n8n\ en Windows. Puedes hacer backup de esta carpeta para no perder tus flujos. Para producción, se recomienda configurar PostgreSQL o MySQL como base de datos.

¿Cuál es la diferencia entre n8n local y n8n Cloud?

n8n local: gratis, corre en tu computadora o servidor, control total sobre los datos, tú gestionas las actualizaciones y el servidor. n8n Cloud: de pago (~$20-50 USD/mes), gestionado por n8n, accesible desde internet sin configuración, actualizaciones automáticas, sin preocuparte por el servidor. Para empezar y para proyectos personales o internos, local es la mejor opción.

Ya tienes n8n instalado — ¿Qué sigue?

Felicidades, ya tienes tu propio servidor de automatización corriendo localmente. Esto es solo el comienzo. Con n8n puedes construir flujos que conecten cientos de servicios: Gmail, WhatsApp, Slack, Google Sheets, Notion, bases de datos, APIs propias y mucho más.
